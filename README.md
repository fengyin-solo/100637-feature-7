# 城市地下综合管廊运行维护管理平台

面向管廊主体台账、入廊管线登记、廊内环境监测、通风排水消防、结构沉降与渗漏处置、巡检检修与隐患整改、入廊作业审批和运维值班的一体化城市地下综合管廊运行维护管理工作台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `urban-utility-tunnel:entries` 这一项，或调用 `resetModule(模块)`。

## 入廊管线台账口径（切换之日 2026-10-06）

- **过滤与排序**：按权属单位、所属舱室、管线类型下拉收窄（全等匹配），过滤只收窄、不改登记原次序（按 id 升序）；分页每页 8 条，页脚总条数即过滤后总条数。筛选条件、页码与停留条目持久化在 `pipeline-view` 存储里，离开页面再回来仍停在原来那条（条目仍命中当前条件时自动落到它所在页）。
- **迁出收起**：办理迁出后管线默认从在用结果里收起，勾选「含已迁出管线」可单独捞出；页脚分别标注两种口径的条数。
- **费用联动**：「入廊费用结算」页的结算单全部由管线台账派生（条数恒等），管线一迁出，权属单位的入廊费、服务费结算单同步标记。**新口径从切换之日起算**：2026-10-06 及以后迁出的，入廊费结清核销、服务费自迁出当月停计；此前迁出的老数据沿用历史结论，不改写，页面标注「老口径」。
- **去重与幂等**：同一管线编号重复登记按编号去重，存量数据迁移时只保留登记时间最早的一版；新登记带提交令牌，同一笔重复提交只认第一次落库，后面的整笔按重复退回。
- **存量迁移**：首次读取（或旧版本地数据）自动跑 `src/data/migration.ts`（SCHEMA_VERSION=2）：去重、给早年缺入廊日期的存量回填日期——规则是以**同舱室最早已知入廊月**为锚点、管线编号升序逐月补（该舱室无任何日期时以 2025-01 为兜底锚点），「待登记」管线尚未入廊不回填；按入廊月份分批，每条备注里写清迁移批次与回填出处。既有状态/迁出结论一律保留。迁移明细可在管线页「存量台账迁移说明」里展开查看。
- **遗留清单**：管线页、巡检任务、值班交接三个入口上报的问题都写入同一份遗留清单（`collab-store`），值班页可统一核销；管线页显示的待处理数与值班页同源同数。管线登记、迁出、问题上报同步写入值班页「台账同步动态」。
- 数据层冒烟验证：`node scripts/smoke.mjs`（内存 localStorage，覆盖去重、回填、过滤分页、幂等、迁出停计与条数一致，共 39 项断言）。
